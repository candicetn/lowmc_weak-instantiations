# lowmc-weak-instantiations

Analyzing weak random linear-layer instantiations in LowMC and LowMC-M.

- `test_type1.py`  
  Experimental verification for Type-I weak instantiations.

- `test_type2.py`  
  Experimental verification for Type-II weak instantiations.

- `test_type3.py`  
  Experimental verification for Type-III weak instantiations.

- `generate_matrices_with_check.py`  
  Matrix-generation and filtering code used for the design discussion. It tests sampled linear layers for detectable Type-I weakness, with optional Type-III filtering.

- `attack_with_weak-instantiation/`  
  Concrete attack verification code for a fixed weak LowMC instance.
